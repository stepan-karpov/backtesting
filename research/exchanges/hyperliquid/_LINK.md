## §3 Order book structure

- **L1 размер:** bid **537 LINK**, ask **296 LINK** — bid в **1.8× тяжелее** ask.
- Медианный размер ордера: **bid 222 LINK vs ask 66 LINK** — соотношение **3.4×**. Самая выраженная bid-ask асимметрия L1 из четырёх активов.
- **Нетривиально: "горбатый" depth profile на bid.** L0=537 → L1=411 (провал −23%) → рост до пика L11=1,017 → затем снижение к L19=848. Ask side: монотонный рост L0=296 → L19=818. Стороны книги структурно разные.
- **Microprice corr = +0.135** (vs SOL +0.267, AVAX +0.157, TIA +0.011).

**Интерпретация:** bid намного тяжелее ask → microprice > mid → структурный бычий байас по книге. При этом крупные продавцы доминируют по объёму (sell 52.3%). Bid давление = мелкий retail, sell давление = крупные участники.

**Для стратегии:** microprice использовать с осторожностью — bid-асимметрия создаёт постоянный структурный сдвиг вверх, не обязательно информативный. Лучше условное использование при нейтральном imbalance.
